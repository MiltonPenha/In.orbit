# 🚀 In.orbit

Aplicação web desenvolvida para **gestão e acompanhamento de objetivos**, permitindo criar metas, acompanhar progresso e organizar tarefas de forma simples e intuitiva.

O projeto foi desenvolvido utilizando **tecnologias modernas do ecossistema JavaScript**, focando em **boas práticas de arquitetura, organização de código e experiência do usuário**.

---

## 🧠 Conceitos aplicados

Este projeto foi desenvolvido aplicando diversos conceitos importantes no desenvolvimento moderno de aplicações web:

* Gerenciamento de estado
* Arquitetura de componentes
* Organização modular de código
* Consumo de APIs
* Boas práticas de UI/UX
* Estrutura escalável de aplicação

---

## ⚙️ Tecnologias utilizadas

Principais tecnologias utilizadas no desenvolvimento:

* **React**
* **TypeScript**
* **Vite**
* **TailwindCSS**
* **Node.js**

## 🚀 Como executar o projeto

### 1️⃣ Clone o repositório

```bash
git clone https://github.com/MiltonPenha/In.orbit.git
```

### 2️⃣ Acesse a pasta do projeto

```bash
cd In.orbit
```

### 3️⃣ Instale as dependências

```bash
npm install
```

ou

```bash
yarn install
```

### 4️⃣ Execute o projeto

```bash
npm run dev
```

A aplicação estará disponível em:

```
http://localhost:5173
```
